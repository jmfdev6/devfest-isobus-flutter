# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolha quem está começando, critique ideias e não pessoas. Assédio e discriminação de qualquer tipo não são tolerados.

Para relatar um comportamento inadequado, abra uma issue ou entre em contato com os mantenedores pelo perfil do GitHub.
